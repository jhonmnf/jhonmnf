## Projetos em destaque

### [Gôndula Reader](https://github.com/jhonmnf/Gondula-reader)

Aplicação web para apoiar a conferência de etiquetas de gôndola. Inclui leitura de códigos pela câmera ou por fotografia, busca manual de produtos e histórico de conferências.

**Tecnologias:** JavaScript, HTML, CSS, Supabase e funções de servidor na Vercel.

[Repositório](https://github.com/jhonmnf/Gondula-reader) · [Aplicação](https://gondula-reader.vercel.app)

Catálogo web com busca de produtos, categorias e visualização de detalhes. Projeto voltado à organização e à consulta de informações em uma interface web.

**Tecnologias:** HTML, CSS, JavaScript e JSON.
