## Projetos em destaque

### [Gôndula Reader](https://github.com/jhonmnf/Gondula-reader)

Aplicação para conferência de etiquetas de gôndola, com leitura de códigos pela câmera ou por fotografia, consulta de produtos e histórico de conferências.

**Tecnologias:** JavaScript, HTML, CSS, funções de servidor na Vercel e Supabase.

[Ver aplicação](https://gondula-reader.vercel.app)

### [Guia de Produtos Azulim](https://github.com/jhonmnf/guia-produtos-azulim)

Catálogo web com busca de produtos, organização por categoria e visualização de detalhes.

**Tecnologias:** HTML, CSS, JavaScript e JSON.
